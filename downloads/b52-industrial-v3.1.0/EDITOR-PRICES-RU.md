# Изменить цены АЗС

1. Войдите в WordPress как **администратор** или **редактор**.
2. В левом меню откройте **Цены АЗС**.
3. Впишите цены напротив **АИ-92, АИ-95, ДТ и ГАЗ**. Примеры: `69,90`, `69.90`, `70`. Единица — ₽/л. Разрешены значения от 0,01 до 999,99, максимум два знака после разделителя.
4. Нажмите единственную кнопку **Сохранить**. Зелёное сообщение означает успешную запись; дата обновится. На странице АЗС новые цены появятся автоматически.

Если есть ошибка, форма покажет сообщение и выделит поля. Никакая из четырёх действующих цен не изменится, пока вся форма не будет правильной. Исправьте ввод и нажмите **Сохранить** ещё раз.

Обычно названия топлива менять не требуется. При необходимости раскройте **Названия топлива (необязательно)**, измените подписи и нажмите ту же кнопку **Сохранить**. Разрешено до 24 символов без HTML.

Код, шорткоды и страницу редактировать не нужно. Начальные значения: АИ-92 — 69,90; АИ-95 — 65,90; ДТ — 70,00; ГАЗ — 41,90 ₽/л. Они взяты из предоставленного референса и не подтверждают текущую стоимость. До первого сохранения на сайте есть соответствующее предупреждение.

Если значения на сайте не обновляются, откройте страницу заново. Если появилось сообщение о невозможности проверки обновления, обратитесь к администратору для настройки кеша по `UPDATE-RU.md`.
