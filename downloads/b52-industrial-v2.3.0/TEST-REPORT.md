# Проверка Б-52 Industrial 2.3.0

## Повторная проверка версии 2.3

- 13 страниц на 320, 375, 768 и 1440 px: 52 проверки HTTP 200, загрузки локальных изображений, отсутствия горизонтального переполнения и корректного расположения шапок.
- В видимом тексте страниц и alt нет служебных надписей о генерации. Описательные alt сохранены.
- У четырёх разделов разные ключи и файлы: База — base, О компании — about, Новости — news, Контакты — contact. В URL есть параметр v=2.3.0.
- 11 сцен, 33 адаптивных WebP. Результаты обработки PNG и исходные JPEG для четырёх фотографий поставляются отдельным архивом.
- Новых ошибок JavaScript не обнаружено. Администратор/редактор сохраняют доступ к четырём полям цен; подписчик получает HTTP 403.
- Публичный endpoint возвращает прежние четыре цены. Снимок options цен/метаданных до и после обновления совпадает; содержимое страниц и фирменные логотипы сохранены.
- PHP-файлы проходят проверку синтаксиса; код управления ценами не менялся.

Рабочий сайт webcrewk.bget.ru не изменялся. Прямой доступ к нему и к baza-b52.ru в среде проверки ограничен сетевой политикой. Проверки выполнены на локальном WordPress, как описано ниже. SMTP/CDN рабочего хостинга повторно не проверялись.

## Базовая проверка функциональности версии 2.2 (сохранена для истории)


Проверялся реальный локальный WordPress 6.9.10, PHP 8.4.24 и SQLite через WordPress SQLite Database Integration. Браузер — Chromium с Playwright. Проверка выполнена в облачной среде; производственный сайт не изменялся.

## Выполнено

- PHP-файлы темы проходят `php -l`; новые JS-файлы проходят `node --check`.
- 13 страниц × 4 ширины (320, 375, 768, 1440 px) = 52 проверки: HTTP 200, без горизонтального переполнения. На всех 12 внутренних страницах шапки расположены горизонтально на большом экране и вертикально на мобильных.
- Проверены загрузка всех локальных изображений с принудительным выполнением отложенной загрузки, responsive srcset, кадрирование и скриншоты основных страниц. Все 24 WebP-файла также проверены декодированием и размерами.
- Все 37 внутренних ссылок и якорей разрешаются; динамический якорь пропуска к содержимому проверен в DOM. Работают открытие мобильного меню и закрытие по Escape.
- Администратор и редактор видят четыре поля цен и одну кнопку сохранения. Автор и подписчик получают HTTP 403 при просмотре раздела и записи; запись гостя отклоняется. Неверный nonce отклоняется с HTTP 403.
- Проверено сохранение через точку и запятую, одного десятичного знака, целого числа и внешних пробелов. Значения читаются обратно из WordPress. Повторное сохранение без изменений распознаётся.
- Отрицательные значения, ноль, превышение 999,99, экспоненциальная запись, лишние знаки, буквы, HTML, пробелы внутри числа, отсутствующие поля и вложенные массивы отвергаются. Все четыре действующие цены остаются прежними.
- Названия топлива редактируются через необязательный раздел формы, сохраняются как текст; некорректное название не меняет ни цены, ни названия.
- Смоделирована выдача старого HTML: браузер получил свежие цены и названия через публичный endpoint с `Cache-Control: no-store`. При ошибке запроса действующие значения из HTML остаются видимыми и появляется предупреждение уточнить стоимость.
- Проверены границы парсера 0,01 и 999,99. Смена темы и повторная активация сохраняют option с ценами, названиями и временем изменения.
- Все 14 созданных установщиком материалов, включая служебную страницу `/blog/`, сохранили хеши содержимого после административных запросов. Пользовательский заголовок и добавленный текст сохраняются при преобразовании шапки.
- Старые секции из четырёх и пяти цен получают динамическую стелу без записи в `post_content`. Произвольная пользовательская фотография с совпадающим обычным именем файла не заменяется.
- Содержимое `content/pages.json`, карта исходных медиа, фирменные логотипы и иконки совпадают с ZIP 2.1 побайтово.
- В форме заявки сохранены поля, согласие, адрес назначения и обработчик. Выполнялись проверки существующего интерфейса; реальное письмо не отправлялось.

- Статический предпросмотр главной, АЗС и политики проверен через локальный HTTP-сервер: локальные изображения, начальные цены и мобильное меню работают. Открытие через `file://` в управляемом Chromium запрещено политикой браузера и не проверено.

## Ограничения

- `baza-b52.ru` недоступен по сетевой политике среды. Не проверены три внешних логотипа партнёров и шесть подлинных архивных фотографий. Их URL/привязки сохранены. Новые изображения не зависят от источника.
- Не проверены доступность внешней Яндекс-карты, внешние ссылки и реальная доставка почты/SMTP.
- Не выполнялись проверки на производственном хостинге, MySQL/MariaDB, PHP 7.4, Safari, Firefox и физических телефонах.
- Реальные плагины кеширования, CDN и WAF владельца не были доступны. Проверен обход старого HTML и no-store endpoint; вызовы очистки плагинов предусмотрены в коде. Настройка внешнего кеша описана в `UPDATE-RU.md`.
- Проверка нового импорта на локальном WordPress и совместимости уже сохранённого содержимого выполнена. Обновление конкретной базы рабочего сайта не выполнялось.

При проверке окружения были предупреждения ядра WordPress о недоступности сервиса проверки обновлений wordpress.org. Предупреждений PHP, относящихся к коду темы, не обнаружено.
