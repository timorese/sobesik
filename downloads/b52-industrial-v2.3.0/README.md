# Б-52 Industrial 2.3.0

- [Скачать установочный ZIP темы](https://github.com/timorese/sobesik/raw/refs/heads/main/downloads/b52-industrial-v2.3.0/b52-industrial-v2.3.0.zip)
- [Скачать оригиналы обработки и исходные фотографии](https://github.com/timorese/sobesik/raw/refs/heads/main/downloads/b52-industrial-v2.3.0/b52-images-originals-v2.3.zip)

Изображения стали светлее и естественнее: мягкий дневной свет, спокойные цвета и менее тяжёлые промышленные фоны. Для четырёх разделов используются разные сюжеты: территория базы, автоцистерна, АЗС после дождя и офис с телефоном. Служебные подписи о генерации на публичных страницах убраны.

В WordPress загрузите ZIP как замену установленной темы и очистите кеш страниц/CDN. Повторный импорт не требуется. Сохранённые цены и тексты не сбрасываются.
