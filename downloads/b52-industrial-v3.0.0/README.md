Новый главный экран с крупным брендовым бензовозом и движением при прокрутке. Обновлены карточки услуг, галерея, принципы и форма. На планшете услуги расположены в две колонки. При уменьшении движения и без JavaScript композиция статична.

## Обновление

Загрузите ZIP темы через WordPress с заменой установленной темы и очистите кеш. Повторный импорт страниц не нужен. Пользовательское содержимое и сохранённые цены не сбрасываются.
