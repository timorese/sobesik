# Очистка заявок для Windows

Скрипт приводит Excel-заявки к единому формату и сохраняет дубли и проблемные строки в отдельном отчёте.

- [Скачать архив zayavki-test.zip](./zayavki-test.zip?raw=true)
- [Инструкция по запуску и правила очистки](./zayavki-test/README.md)
- [Исходный скрипт](./zayavki-test/clean_zayavki.py)
- [Чистый файл](./zayavki-test/results/zayavki_clean.xlsx)
- [Отчёт о проблемах и полный аудит](./zayavki-test/results/zayavki_problems.xlsx)

Для Windows: распакуйте архив, установите Python 3.10+ и откройте `run.cmd`. Для первой установки зависимости нужен интернет.

Результат: 48 исходных строк, 24 чистые записи, 18 дублей и 6 проблемных записей без включения в чистый файл. Все строки сохранены в аудите; 7 автоматических тестов прошли.

Перед сдачей задания нужно добавить настоящий полный экспорт истории работы с AI в `ai_history` и написать шесть строк о работе своими словами. Архив содержит инструкцию и заготовку, но не экспорт беседы.
