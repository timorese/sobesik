# Очистка заявок из Excel

Скрипт обрабатывает таблицу заявок: приводит телефоны к формату `+7XXXXXXXXXX`,
даты — к `YYYY-MM-DD`, убирает лишние пробелы в именах и оставляет одну запись
на телефон. Проблемные строки и удалённые дубли сохраняются в отдельном отчёте.

## Запуск в Windows

Понадобятся **Python 3.10 или новее** и интернет для первой установки зависимости.
Устанавливать Excel для запуска скрипта не нужно.

1. [Скачайте архив zayavki-test.zip](https://github.com/timorese/sobesik/raw/refs/heads/main/zayavki-test.zip).
2. Распакуйте архив целиком. Откройте вложенную папку `zayavki-test`, в которой находятся `run.cmd` и `clean_zayavki.py`.
3. Если Python ещё не установлен, установите его с [python.org](https://www.python.org/downloads/windows/), включив **Add Python to PATH**.
4. Дважды щёлкните `run.cmd`. Он создаст окружение `.venv`, установит `openpyxl` и обработает приложенный `zayavki.xlsx`.
5. Результаты появятся в папке `results`. Готовые результаты уже приложены к архиву; этот запуск обновляет их. Перед запуском закройте файлы результатов в Excel.

Если вы клонировали репозиторий, скрипт и `run.cmd` находятся в папке `sobesik\zayavki-test`.

## Обработка другого файла

Откройте PowerShell в папке, где лежит `run.cmd`, и выполните:

```powershell
.\run.cmd "C:\Data\new.xlsx" --period 2027-04 --out-dir "C:\Data\result"
```

В обычной командной строке Windows (CMD) та же команда начинается с `run.cmd`.

Входной файл должен иметь расширение `.xlsx` и заголовки в первой строке:
`Имя`, `Телефон`, `Дата заявки`, `Источник`. Порядок колонок может быть любым.
В примере выше результаты — `new_clean.xlsx` и `new_problems.xlsx` — будут
сохранены в `C:\Data\result`. Исходный файл не меняется.

Параметр `--period` задаёт ожидаемый месяц в формате `YYYY-MM`.
Без него скрипт пытается определить месяц по большинству однозначных дат.
Для выгрузки за несколько месяцев укажите `--no-infer-period`.
Для повторной записи существующих результатов добавьте `--force`.

## Результаты на предоставленных данных

| Итог обработки | Количество |
| --- | ---: |
| Исходные непустые строки | 48 |
| Записи в чистом файле | 24 |
| Удалённые дубли | 18 |
| Проблемные записи без включения в чистый файл | 6 |

- [Чистый файл](./zayavki-test/results/zayavki_clean.xlsx) содержит четыре исходные колонки в нормализованном виде.
- [Отчёт](./zayavki-test/results/zayavki_problems.xlsx) содержит листы `Проблемы`, `Аудит` и `Сводка`.

В аудите сохранены все 48 строк: **24 + 18 + 6 = 48**.
На листе `Проблемы` — **26 строк**, включая удалённые дубли и конфликты имён.
Две выбранные записи с конфликтом имён также присутствуют в чистом файле:
по условию задания одинаковый телефон считается одним человеком.

Неоднозначные даты разбираются с учётом периода выгрузки. Нераспознанные даты
и даты вне периода сохраняются в отчёте с причиной. Например, `19.09.2062`
помечается как дата вне сентября 2026 года; год автоматически не исправляется.

[Подробные правила очистки и параметры скрипта](./zayavki-test/README.md).

## Проверка

После первого запуска `run.cmd` выполните в PowerShell из папки `zayavki-test`:

```powershell
.\.venv\Scripts\python.exe -m unittest -v test_clean_zayavki.py
```

Все **7 автоматических тестов прошли**. Результаты проверки исходного файла —
в [validation.txt](./zayavki-test/validation.txt), вывод тестов —
в [tests.log](./zayavki-test/tests.log). Логика Python проверена в Linux;
фактический запуск Windows-обёртки в этой среде не выполнялся.
